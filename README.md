# AI in Science: Early Insights, read visually

An interactive reading of the paper *AI in Science: Early Insights* (Codreanu, Imas, Mateos-Garcia et al., Google, Google DeepMind and MIT FutureTech, September 2026).

Open `index.html` in a browser. No build step. Every number comes from the paper; figure images in `figures/` are reproduced from it.
